# Phase 1 开发拆分

## 已实现范围

1. 项目骨架：Next.js、FastAPI、SQLAlchemy、Alembic、Docker Compose。
2. 登录：本地管理员、签名访问令牌、API 统一认证保护。
3. 纳新档案：54 次原始问卷提交聚合成个人档案，支持搜索、质量筛选、新建和详情关联。
4. 资料分析助手：多文件上传、材料类型识别、摘要、事实、疑点与建议面试问题，并可关联个人档案。
5. 人格标签：Big Five 固定维度、语言信号强度、置信度、原文依据和材料不足状态。
6. 成员中心：仅展示和管理正式社团成员，与纳新候选人分开。
7. 面试：直接选择纳新档案，管理场次、问题、结构化逐字稿与 Speaker 角色。
8. Provider：Mock Meeting、Mock 资料分析与 Mock 面试证据分析。
9. Evidence Engine：JSON Schema 校验、来源保存、标签聚合。
10. 动态画像：评分、可信度、趋势、证据数量与来源展开。
11. 人工审核：接受、拒绝、修改状态，不删除原始 Evidence。
12. 信息架构：主导航聚焦纳新档案、成员中心、面试管理与证据审核；工作台留待后续开发。

## 接下来的 Phase 1 增量

- 真实模型 Provider、OCR 与二进制文档正文抽取。
- 可配置的问卷设计器与增量导入任务。
- 资源级 RBAC 查询过滤与权限管理界面。
- OpenAI Compatible Provider 与真实 JSON Schema 校验重试。
- 完整操作日志查询页与敏感字段脱敏策略。
- 团队工作台、项目协作与推荐能力。
