# BlueROV2 model attribution

`bluerov2-optimized.glb` is converted from the BlueROV2 simulation mesh published by
`vicoslab/bluerov2` and used here under the repository's Apache-2.0 license.

- Source: https://github.com/vicoslab/bluerov2
- Original asset: `bluerov2_description/meshes/bluerov2_noprop.dae`
- Conversion: Collada to binary glTF, then Meshopt-compressed for browser delivery
